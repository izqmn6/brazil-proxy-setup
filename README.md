## The Four Types of Brazil Proxies (And Which One You Actually Need)

Not all Brazilian IPs are created equal. The IP address itself maters less than the network it sits on, because that's what websites use to score how "real" your traffic looks.

### Datacenter Proxies

These come from server farms hosted in commercial data centers. Fast, stable, and the cheapest option per IP by a wide margin. The catch: target sites can fingerprint datacenter ASNs and either block or rate-limit them aggressively. Good for Brazilian sites that don't run heavy anti-bot stacks.

### Residential Proxies

Routed through real Brazilian household connections, these IPs belong to actual ISPs like Claro, Vivo, TIM, or Oi. Detection systems treat them as ordinary user traffic, which is why scrapers reach for residential when datacenter gets blocked. Pricing is typically per gigabyte rather than per IP.

### Static Residential (ISP) Proxies

The hybrid play. The IP is hosted in a data center but registered under a residential ISP, so you get datacenter sped and stability with residential-grade trust. Popular for managing accounts that need a consistent IP across long sessions.

### Mobile Proxies

Routed through Brazilian 4G/5G mobile cariers. Highest trust score, highest cost, mostly used for sneaker coping, ad ops, and social media work where mobile-only fingerprints matter.

> **Quick takeaway**: For most Brazil scraping projects, start with datacenter and graduate to residential when you hit blocks. For account management, go static residential. Mobile is a niche.
